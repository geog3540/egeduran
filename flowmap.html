Assignment 1: Web Mapping Workflow

This notebook prepares polygon data for web mapping by converting shapefiles to TopoJSON, validating WGS84 coordinates, uploading TopoJSON and CSV files, and joining spatial features with tabular attributes in Observable.

Assignment 2: Classification and Colors

This notebook compares classification methods and color scales for a normalized water-surface variable, including unclassed, quantile, equal interval, natural breaks, and manual threshold approaches.

Assignment 3: Choropleth Mapping

This project builds a choropleth map by joining county geometry with tabular data, classifying values with natural breaks, applying a D3 color scale, and adding a legend and hover values.

Assignment 4: Graduated Symbol Mapping

This notebook maps the percentage of poor bridges by Iowa county using graduated symbols placed on county midpoints, allowing bridge-condition patterns to be compared across the state.

Assignment 5: Bivariate Choropleth Mapping

This project maps Iowa bridge vulnerability using a bivariate choropleth that combines bridge condition and population exposure, showing both variables together at the county level.

Assignment 6: Flow Mapping

This page presents a flow map of internal migration in Argentina, including the exported map image, FlowMapper project file, layer settings, and interpretation of major origin–destination patterns.
